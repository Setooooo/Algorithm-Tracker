# 普通线段树练习：单点加、区间求和

这是一道自拟基础练习，配套代码为 [Segment_Tree_Practice.cpp](Segment_Tree_Practice.cpp)。先完成普通线段树，再练习按值域统计出现次数，最后添加前缀版本，过渡到主席树。

这一轮只实现建树、单点更新和区间查询。

## 题目描述

给定一个长度为 `n` 的整数数组 `a`，下标从 `1` 开始。接下来执行 `m` 次操作：

- `1 pos delta`：将 `a[pos]` 增加 `delta`，`delta` 可以为负数。
- `2 L R`：输出当前数组闭区间 `[L, R]` 内所有元素的和。

操作按输入顺序执行，更新会影响后续查询。

## 输入格式

本练习只有一组数据，没有测试组数 `T`。

第一行输入两个整数 `n, m`。

第二行输入 `n` 个整数，表示初始数组。

接下来 `m` 行，每行表示一次操作，格式见题目描述。

本练习约定：

- `1 <= n, m <= 100000`。
- 初始元素的绝对值不超过 `1000000000`。
- 每次更新的 `delta` 的绝对值不超过 `1000000000`。
- `1 <= pos <= n`，`1 <= L <= R <= n`。

## 输出格式

对于每个操作 `2 L R`，输出一行区间和。使用 `long long` 保存元素值和区间和。

## 模板约定

这一轮，树上节点的区间是**原数组的下标范围**。

| 名称 | 含义 |
|---|---|
| `a[i]` | 用于建树的初始数组元素，采用从 `1` 开始的下标 |
| `p` | 当前线段树节点的编号 |
| `l, r` | 当前节点负责的原数组闭区间 `[l, r]` |
| `tree[p]` | 当前数组在 `[l, r]` 内的元素和 |
| `pos, delta` | 本次单点更新的位置和增加量 |
| `L, R` | 本次查询的目标区间 |

根节点编号为 `1`，左右孩子编号分别约定为 `p * 2` 和 `p * 2 + 1`。模板已分配 `4 * n + 5` 个位置供 `tree` 使用。

输入、数组分配、函数调用和输出都已写好。你需要完成三个函数：

1. `build(p, l, r)`：根据初始数组建立这段区间的统计信息。
2. `query(p, l, r, L, R)`：返回当前数组在查询区间中的元素和。
3. `add(p, l, r, pos, delta)`：完成一次单点加，并维护相关节点的统计信息。

建议先写 `build`，再写 `query`，最后写 `add`。前两步可以先用只有查询的输入验证。

模板中的函数体目前留空，`query` 中的 `return 0` 是编译用占位值，需要你实现后替换。

## 自拟样例 1：查询与多次更新

输入：

```text
5 8
2 5 4 1 3
2 1 5
1 3 2
2 2 4
1 1 -3
2 1 1
2 1 5
1 5 -3
2 4 5
```

输出：

```text
15
12
-1
14
1
```

第一次更新后数组为 `[2, 5, 6, 1, 3]`；第二次更新后数组为 `[-1, 5, 6, 1, 3]`；第三次更新后数组为 `[-1, 5, 6, 1, 0]`。
