# I. 小鸡的排列构造的 checker

来源：[2025 牛客寒假算法基础集训营 6 · I 题](https://ac.nowcoder.com/acm/contest/95338/I)。

## 题目描述

给定一个长度为 `n` 的排列 `a`。也就是说，`a` 恰好由 `1` 到 `n` 这 `n` 个整数构成，每个整数出现一次。数组下标从 `1` 开始。

你需要回答 `m` 次询问。每次询问给出三个整数 `l, r, c`，其中 `l <= c <= r`。

假设将原数组中下标位于闭区间 `[l, r]` 的元素按从小到大的顺序排列，区间外的元素保持原位。请输出：**原来位于下标 `c` 的那个元素，在这次排序后位于整个数组的哪个下标？**

每次询问相互独立，均以最初输入的排列为基础，询问不会实际修改原数组。

注意：`c` 是原数组中的下标；答案也是整个数组中的下标，使用从 `1` 开始的编号。

## 输入格式

第一行输入一个整数 `T`，表示测试数据组数。

对于每组数据：

1. 第一行输入两个整数 `n, m`，分别表示排列长度和询问次数。
2. 第二行输入 `n` 个整数 `a[1], a[2], ..., a[n]`，表示初始排列。
3. 接下来 `m` 行，每行输入三个整数 `l, r, c`，表示一次询问。

## 输出格式

按照输入顺序，对每次询问输出一行，一个整数，表示目标元素排序后在整个数组中的下标。

## 约束说明

- `a` 是 `1` 到 `n` 的排列。
- 每次询问满足 `1 <= l <= c <= r <= n`。
- 你提供的参考代码按 `n` 约为 `10^5` 的规模分配数组，可以据此考虑实现的效率和空间开销；这不作为已核实的官方上限。
- `T, n, m` 的官方上限、多组数据的总规模以及时间、空间限制，请以原题为准。

## 自拟样例

### 输入

```text
2
5 5
2 5 4 1 3
2 5 3
1 5 1
1 3 2
2 4 4
1 5 4
3 3
3 1 2
1 3 1
1 2 1
2 3 3
```

### 输出

```text
4
2
3
2
1
3
2
3
```

### 说明

第一组数据的第一次询问为 `2 5 3`。原来下标 `3` 的元素是 `4`，区间 `[2, 5]` 的元素为 `[5, 4, 1, 3]`。排序后整个数组为 `[2, 1, 3, 4, 5]`，目标元素 `4` 位于下标 `4`，因此输出 `4`。

第一组数据的第三次询问仍然使用初始排列 `[2, 5, 4, 1, 3]`。原来下标 `2` 的元素是 `5`，将区间 `[1, 3]` 排序后，它位于下标 `3`，因此输出 `3`。
